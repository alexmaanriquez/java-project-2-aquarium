# Project 2: Aquarium

## Overview
This project is a Java graphics program that uses the edu.cymbal.graphics Painter library to create a colorful underwater aquarium scene.

## Planned Elements

### Sea Creatures
- Two blue fish of different sizes.
- Two orange fish of different sizes.
- Two starfish of different sizes and colors.

### Decorations
- Green seaweed.
- Pink and purple coral.
- Floating bubbles.
- A treasure chest.

## Programming Concepts
This project will demonstrate:
- Creating and calling methods.
- Using parameters to customize shapes.
- Reusing methods to create larger objects.
- Using loops to repeat drawing instructions.
- Organizing a Java program into smaller tasks.

## Current Progress
The initial project plan and program structure are being developed. The next step is implementing the drawing methods and constructing the complete aquarium scene.
